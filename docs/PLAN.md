# DeskIsle(桌島)— 專案計畫

> 你的檔案,就是島嶼。

DeskIsle 會讀取 Windows 桌面上每個圖示的位置,即時畫出一張「跟著檔案長出來」的桌布:
有檔案的地方是沙灘,沒有檔案的地方是海洋。把檔案拖到別處,陸地就跟著移動。

目前版本:0.0.8(2026-11-12)

---

## 1. 名稱

**DeskIsle(桌島)** = Desktop + Isle。

- 一個孤立的檔案會變成一座小島,一整排檔案會連成一片海岸,名稱直接說出這件事。
- 不綁死「沙灘」這個主題,換成草原、火山、宇宙也說得通。
- 套件名稱 `deskisle`,短、好打、沒有空格。

備選(若想改名,只要改套件資料夾名稱與 `APP_NAME` 常數):

| 名稱 | 中文 | 感覺 |
|---|---|---|
| Tideline | 潮線 | 較詩意,強調海岸線 |
| Atoll | 環礁 | 最短,但較難聯想到桌面 |
| TerraDesk | 桌面大地 | 強調「地形」,較中性 |

## 2. 核心概念

1. **偵測**:取得桌面每個圖示(檔案、資料夾、捷徑)在螢幕上的矩形範圍。
2. **地形**:把這些矩形當成「陸地種子」,算出整個螢幕每個像素到最近陸地的距離。
   相近的圖示會自動融合成一整片陸地,落單的圖示成為小島。
3. **上色**:依距離套用主題色帶 —— 乾沙 → 濕沙 → 浪花 → 淺灘 → 深海。
4. **裝飾**:依地帶放上椰子樹、貝殼、珊瑚、魚群、小船……(每個主題不同)。
5. **套用**:存成圖片並設為桌布。
6. **監看**:圖示一移動(新增、刪除、拖曳、解析度改變)就重畫。

設計原則:

- **圖示永遠在陸地上**:海岸線的不規則起伏幅度一定小於陸地邊界留白。
- **裝飾物不擋圖示**:裝飾物不會蓋到任何圖示,也不會彼此重疊。
- **穩定**:同樣的圖示排列 + 同一個種子永遠產生同一張圖。
- **每次都不一樣**:自動跟隨時,圖示排列一改變就換一個新種子再重畫,海岸線與裝飾物整個換新(可在「運作」頁關閉;關閉後移動一個圖示只會改變它附近的地形與裝飾物)。
- **可還原**:第一次套用前備份原本的桌布,一鍵還原。
- **省資源**:平常幾乎不佔 CPU、完全不用顯示卡(見第 9 節)。
- **免安裝**:打包成單一 exe,複製到別台電腦就能用(見第 8 節)。

## 4. 技術選型

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | Python 3.9+(64 位元) | 影像運算有 numpy 可用;開發速度快 |
| macOS 系統呼叫 | 內建的 `osascript`(AppleScript / JXA) | 不需要 pyobjc;讀 Finder 圖示位置、NSScreen、設定桌布 |
| 圖示偵測 | `ctypes` 直接呼叫 Win32 | 不需額外套件;能取得完整矩形(圖示+文字標籤) |
| 影像運算 | numpy | 1920×1080 的地形與上色約 0.45 秒 |
| 影像輸出與裝飾物繪製 | Pillow | 縮放、PNG 輸出、向量繪圖 |
| 設定介面 | tkinter | Python 內建,打包後不需額外安裝;閒置時不耗 CPU |
| 系統匣 | pystray | 小、純 Python;沒有時自動退回「縮到工作列」 |
| 套用桌布 | `SystemParametersInfoW` + 登錄檔 | Windows 標準做法 |
| 打包 | PyInstaller(單一檔案、無主控台) | 產生一個 exe,內含 Python 與所有相依套件 |

執行時相依套件:`numpy`、`Pillow`、`pystray`(選用,只有 Windows 使用)。打包工具:`pyinstaller`。

## 6. 關鍵技術細節

### 6.1 圖示偵測

桌面圖示其實是檔案總管裡的一個 ListView 控制項:

```
Progman(或某個 WorkerW)
  └─ SHELLDLL_DefView
       └─ SysListView32 "FolderView"   ← 目標
```

1. 用 `FindWindowEx` 找到它。先找 `Progman` 底下,找不到再逐一找 `WorkerW`。
2. `LVM_GETITEMCOUNT` 取得圖示數量。
3. 對每個圖示送 `LVM_GETITEMRECT`(外框)與 `LVM_GETITEMTEXTW`(名稱)。
   這兩個訊息需要一塊「對方行程看得到」的記憶體來放結果,
   所以用 `VirtualAllocEx` 在檔案總管行程配置一小塊可讀寫(不可執行)的緩衝區,
   再用 `ReadProcessMemory` 讀回來。這是桌面圖示工具的標準做法,只讀不改。
4. 所有訊息都用 `SendMessageTimeout`,檔案總管卡住時不會跟著卡死。
5. 監看時不讀名稱(用不到),跨行程呼叫少一半。

限制:程式必須與檔案總管同為 64 位元。

### 6.8 macOS

所有系統查詢都透過內建的 `osascript`,不需要安裝 pyobjc:

| 功能 | 做法 |
|---|---|
| 螢幕清單、Retina 倍率 | JXA 讀 `NSScreen.screens`(frame、backingScaleFactor、NSScreenNumber) |
| 圖示位置 | AppleScript 問 Finder `desktop position of every item of desktop`(圖示中心),外框依圖示大小、文字大小估算 |
| 圖示是否隱藏 | `defaults read com.apple.finder CreateDesktop` |
| 套用桌布 | JXA 呼叫 `NSWorkspace.setDesktopImageURL(forScreen:)`,逐一設定螢幕 |
| 登入啟動 | `~/Library/LaunchAgents/com.deskisle.app.plist` |
| 單一執行個體 | 暫存資料夾裡的 Unix socket;第二個執行個體連進來 = 叫出視窗 |
| 系統匣 | 不使用(pystray 在 macOS 要佔用主執行緒,與 tkinter 衝突);關閉視窗時縮到 Dock |

- 座標一律用「點」,原點是虛擬桌面左上角;套用時依每個螢幕的 Retina 倍率畫成實體像素。
- 呼叫一次 osascript 約 0.1 秒,所以只在 `~/Desktop` 或它的 `.DS_Store` 變動時才問 Finder,
  另外每 10 秒保險重讀一次;螢幕清單每 15 秒更新一次。
- 第一次問 Finder 時 macOS 會要求「自動化」權限。打包的 `.app` 在 Info.plist 加上
  `NSAppleEventsUsageDescription`(見 build.py),否則系統會直接拒絕。
- macOS 只會改目前桌面空間(Space)的桌布。

### 6.2 座標對應

- 啟動時把行程設為 Per-Monitor DPI Aware,確保拿到的是實體像素。
- ListView 用戶區座標 → `ClientToScreen` → 減去虛擬桌面左上角 → 圖片座標。
- 每個螢幕各自畫一張圖,尺寸 = 該螢幕的實體像素(直向螢幕就是直的圖),
  只用落在該螢幕內的圖示計算地形;種子加上螢幕序號,同尺寸的螢幕也不會長得一樣。
- 單螢幕:用 `SystemParametersInfo` 以「填滿」套用(1:1)。
- 多螢幕:用 Windows 8 起的 `IDesktopWallpaper` COM 介面(以 ctypes 直接呼叫函式表),
  只對使用者勾選的螢幕 `SetWallpaper`,其他螢幕不動。螢幕以裝置路徑辨識,拔插後設定仍對得上。
  COM 不能用時退回舊做法:所有螢幕合成一張大圖,以「跨螢幕」套用。
- 「像素」類參數會乘上系統縮放比例,在 150% 縮放下看起來比例一致。

### 6.3 地形演算法

距離場先在 1/4 解析度計算,再以雙三次插值放大。

1. **每個圖示的距離**:點到矩形的距離 `d_i`(矩形內為 0)。
2. **平滑融合**:`d = -k · ln( Σ exp(-d_i / k) )`
   - 只有一個圖示時 `d = d_i`;
   - 兩個圖示靠近時,中間的 `d` 會比單獨計算更小 → 陸地自然連在一起;
   - 圖示越密集 `d` 越負 → 代表「越內陸」。
3. **海岸線**:`sd = d − 邊界留白 + 起伏幅度 × 雜訊`
   - `sd < 0` 是陸地,`sd > 0` 是水域,數值就是離海岸線的像素距離;
   - 雜訊是固定種子的分形雜訊,只跟螢幕位置有關,圖示不動時海岸線不會變;
   - 起伏幅度被限制在邊界留白的 80% 以內 → 保證圖示矩形一定在陸地上。
4. 沒有任何圖示(或圖示被隱藏)時 → 整片海洋。

### 6.4 上色與質感

- **色帶**:每個主題是一串 `(sd 距離, 顏色)` 控制點,展開成查表後一次對應整張圖。
- **浪花**:沿著距離場的等高線畫出一圈圈平行海岸的線,離岸越遠越淡,
  並用雜訊打斷成一段一段;緊貼海岸的第一圈不打斷。
- **顆粒與光影**:陸地有細顆粒、大塊色斑與浮雕光影;水域有輕微明暗變化
  (沙漠主題的「水域」是沙丘,所以也有浮雕)。
- **彩色雲霧**:宇宙、夜晚主題在水域疊上兩層彩色雜訊(星雲)。
- **光點**:宇宙主題的星星、夜晚主題的發光浮游生物,位置固定、只出現在水域。
- **可讀性**:桌面圖示文字是白色帶陰影,陸地顏色避免接近純白(極地主題最淺,文字靠陰影辨識)。

### 6.5 裝飾物

**繪製**:每種裝飾物是一個繪圖函式(`decor.py`),以 4 倍大小繪製再縮小,邊緣平滑。
不使用任何外部圖檔,所以 exe 不需要附帶資源。每種有 4 種長相、可指定配色,
畫好的圖會快取,畫完一張桌布後清掉。

目前 19 種:椰子樹、岩石、海星、貝殼、珊瑚、魚群、小船、樹、花叢、荷葉、隕石坑、
行星(有環/無環)、星系、星芒、仙人掌、浮冰、雪松、發光裂縫、水母。

**擺放**:

1. 螢幕切成固定的 46 像素格子,每格有一個固定的候選位置與一組固定亂數
   (只跟種子與螢幕位置有關)。
2. 候選位置的 `sd` 值決定它在哪個地帶;主題的規則說明每個地帶可以放什麼、機率多少、多大。
   例:沙灘主題的椰子樹放在 `sd -44 ~ -13`(靠近海岸的陸地),珊瑚放在 `14 ~ 100`(淺灘)。
3. 外框碰到任何圖示的候選位置直接放棄 → 裝飾物不會擋住圖示。
4. 與已放下的裝飾物太近的也放棄 → 不重疊。
5. 陸地上的東西加上右下方的柔和影子;水面下的東西(珊瑚、魚)半透明、沒有影子。

因為格子與亂數是固定的,移動一個圖示只會讓它附近的裝飾物出現或消失,遠處完全不變。

### 6.7 套用與還原

- 輸出 PNG 到 `%LOCALAPPDATA%\DeskIsle\`,在 `wallpaper_a.png` / `wallpaper_b.png`
  兩個檔名間交替 —— 路徑每次都不同,Windows 一定會重新載入。
- 第一次套用前,把原本桌布的路徑、樣式記到 `state.json`,並複製一份原圖備份。
- 還原時把路徑與樣式設回去,並清除 `state.json`。
- 若原本使用「Windows 焦點」或「幻燈片」,還原後圖片會回來,
  但自動更換需要到 設定 → 個人化 → 背景 重新選一次。

## 7. 設定介面

視窗最上面是標題列(程式圖示、名稱、標語,右邊顯示自動跟隨狀態與版本),
左邊是分頁,右邊是一張像螢幕的預覽卡片,下面是「套用到桌布」「還原原本桌布」「結束程式」。

外觀全部用 tkinter 內建的 ttk(以 clam 為底)自訂樣式,配色取自程式圖示(深海藍、淺灘、沙色);
標題列背景、主題縮圖、勾選框都是 Pillow 畫的圖,不需要額外套件,也不用附帶圖檔。
間距會乘上系統縮放比例;中文字型在 Windows 用微軟正黑體,macOS 用蘋方。

**外觀頁**:主題(每個主題一張小縮圖,點一下就選)、海岸線形狀(種子,可按「換一個」)、
陸地留白、融合程度、海岸起伏、裝飾物數量。

**螢幕頁**:要更新的螢幕(每個螢幕一個勾選框,顯示編號、解析度、橫向/直向;至少要勾一個)。
多螢幕時預覽依實際排列畫出每個螢幕並標上編號,沒勾選的螢幕畫成灰色斜線。

外觀頁與螢幕頁調整時右邊預覽立刻更新,但**不會**動到桌布;按「套用到桌布」才生效並存檔。

**運作頁**:自動跟隨桌面圖示、圖示移動後換一種海岸線形狀、全螢幕時暫停、開機自動啟動、檢查間隔、背景檢查間隔、穩定等待。
這一頁的設定改了立刻生效並存檔。

**測試頁**(只有以原始碼執行時才有):在預覽上畫圖示外框、用隨機假圖示測試排列、
偵測圖示清單、效能測試、輸出全尺寸圖、執行自動化測試、環境資訊。全部不會動到桌布。

打包後看不到測試頁,有兩層保險:

1. `ui/app.py` 偵測到自己是打包後的執行檔(`sys.frozen`)時不載入測試頁;
2. `build.py` 打包時直接把 `deskisle.ui.dev` 模組排除,exe 裡根本沒有這段程式。

其他行為:

- 關閉視窗 = 縮到系統匣,監看繼續;系統匣選單可開啟設定、切換自動跟隨、結束。
- 再次啟動程式時不會開第二個,而是把已在執行的視窗叫出來。
- 第一次開啟時「自動跟隨」是關的 —— 使用者自己開啟後才會開始更換桌布。

## 8. 打包

```
pip install pyinstaller
python build.py        →  dist\DeskIsle.exe(約 25 MB)
```

- 單一檔案、沒有主控台視窗;內含 Python、numpy、Pillow、tkinter、pystray。
- 目標電腦需求:64 位元 Windows 10 / 11。不需要安裝任何東西。
- 設定與產生的桌布放在該電腦的 `%LOCALAPPDATA%\DeskIsle\`。
- `DeskIsle.exe --selftest 檔案.json`:不開視窗、不動桌布的自我檢查
  (偵測圖示、每個主題畫一張小圖、建立介面),結果寫成 JSON。用來確認打包結果能運作。
- exe 沒有簽章,在其他電腦第一次執行時 Windows SmartScreen 可能會警告,
  需要按「其他資訊 → 仍要執行」。
- 單一檔案模式每次啟動要先解壓縮,啟動約需 2 秒。

## 9. 省資源設計

桌布是一張靜態圖片:畫好之後由 Windows 自己顯示,DeskIsle 不佔用顯示卡,也沒有動畫。
CPU 的花費只有兩種:**檢查圖示位置**(很便宜,但一直在做)與**重畫**(較貴,但很少發生)。

| 做法 | 效果 |
|---|---|
| 分級輪詢:正對桌面時每 1 秒檢查;用其他視窗時每 3 秒 | 大部分時間檢查次數降為三分之一 |
| 全螢幕程式(遊戲、影片、簡報)或螢幕鎖定時完全暫停 | 不跟遊戲搶資源 |
| 監看時不讀圖示名稱 | 每次檢查的跨行程呼叫減半 |
| 排列改變且穩定後才重畫(防抖動) | 自動排列時不會連畫好幾張 |
| 平滑紋理以 1/2、1/4 解析度計算再放大;色帶改用查表 | 重畫從 0.8–1.5 秒降到約 0.45 秒 |
| 監看與重畫在「背景優先權」執行緒 | 重畫時 CPU、磁碟都排在前景程式之後 |
| 畫完清除快取並把記憶體還給系統 | 常駐記憶體維持在約 30 MB |
| 關閉數學函式庫的執行緒池 | 不會多出一排閒置執行緒 |
| 介面不輪詢;視窗隱藏時不畫預覽;預覽只畫縮小版(約 50 毫秒) | 縮在系統匣時介面完全不耗 CPU |

實測(Windows 11、1920×1080、37 個圖示):

| 項目 | 數值 |
|---|---|
| 檢查一次圖示位置 | 約 2–4 毫秒 |
| 重畫一張全尺寸桌布 | 0.43–0.52 秒(單核心) |
| exe 縮在系統匣閒置(未開啟自動跟隨) | 20 秒內 16 毫秒 CPU(單核心的 0.08%),記憶體約 30 MB |
| 監看迴圈(套用步驟以假的取代) | 20 秒內 0–31 毫秒 CPU(單核心的 0.16% 以下) |
| 顯示卡 | 不使用 |

## 10. 邊界情況

| 情況 | 處理 |
|---|---|
| 桌面沒有圖示 / 圖示被隱藏 | 整片海洋 |
| 檔案總管重啟或當掉 | 訊息逾時 → 這一輪跳過,下一輪重試 |
| 解析度或縮放比例改變 | 畫面尺寸是特徵值的一部分 → 自動重畫 |
| 多螢幕 | 每個螢幕各自畫、只更新勾選的螢幕;系統不支援時畫成一張大圖以「跨螢幕」套用 |
| 勾選的螢幕被拔掉 | 設定保留它的代碼;勾選的螢幕都不在時改為更新全部螢幕 |
| 圖示有一部分在螢幕外 | 矩形裁切到畫面內;完全在外的忽略 |
| 32 位元 Python | 啟動時報錯並說明原因 |
| 連按兩次套用 | 已是 DeskIsle 桌布時不重複備份 |
| 設定檔壞掉或是舊版格式 | 壞掉 → 用預設值並提示;舊版 → 缺少的項目用預設值補上 |
| 套用失敗(磁碟滿等) | 狀態列顯示原因,下一輪再試;錯誤寫入 `deskisle.log` |
| 重複啟動程式 | 只保留一個,把原本的視窗叫出來 |

## 11. 命令列(開發用;exe 不包含)

```
python -m deskisle                     開啟設定介面
python -m deskisle icons               列出偵測到的圖示(唯讀)
python -m deskisle preview [-o 檔案]   畫一張圖存檔,不動桌布;--debug 加上圖示框線
python -m deskisle apply               畫一次並設為桌布
python -m deskisle watch               持續監看(Ctrl+C 結束)
python -m deskisle restore             還原成原本的桌布
python -m deskisle themes              列出主題
python -m deskisle config [--save]     顯示/儲存設定
```

共用選項:`--theme 主題`、`--seed 數字`、`--decorations 數量`。

## 12. 設定

`%LOCALAPPDATA%\DeskIsle\config.json`(不存在時使用預設值;介面會自動寫入):

| 鍵 | 預設 | 說明 |
|---|---|---|
| `theme` | `beach` | 主題 |
| `seed` | `7` | 雜訊種子,決定海岸線形狀與裝飾物位置 |
| `margin` | `46` | 圖示外圍保留多少像素的陸地 |
| `blend` | `26` | 融合半徑,越大越容易連成一片 |
| `roughness` | `22` | 海岸線起伏幅度(自動限制在 `margin` 的 80% 內) |
| `decorations` | `1.0` | 裝飾物數量:0 = 不畫,1 = 標準,2 = 兩倍 |
| `follow` | `false` | 啟動時是否自動跟隨桌面圖示 |
| `poll_interval` | `1.0` | 正對桌面時每幾秒檢查一次 |
| `idle_interval` | `3.0` | 其他時候每幾秒檢查一次 |
| `debounce` | `0.5` | 排列穩定多久後才重畫(秒) |
| `pause_when_busy` | `true` | 全螢幕程式執行或螢幕鎖定時暫停 |
| `reseed_on_move` | `true` | 自動跟隨時,圖示排列一改變就換一個新的 `seed` 並寫回設定檔 |
| `screens` | `[]` | 要更新桌布的螢幕代碼(裝置路徑);空 = 全部螢幕 |

像素類參數以 100% 縮放為基準,程式會自動乘上系統縮放比例。

## 14. 風險與對策

| 風險 | 對策 |
|---|---|
| Windows 改版後桌面視窗結構改變 | 兩條尋找路徑(Progman / WorkerW);失敗時給明確錯誤訊息;COM 方案列為備援 |
| 防毒軟體對跨行程讀取記憶體、或對未簽章的打包 exe 敏感 | 只配置可讀寫(不可執行)的記憶體、只讀取 ListView 資料;必要時簽章或改用資料夾模式打包 |
| 淺色陸地讓白色圖示文字不易閱讀 | 陸地避免近白色;提供多個深色陸地主題 |
| 4K/多螢幕時繪圖變慢、吃記憶體 | 全程 float32;紋理降解析度;只在排列改變時重畫;畫完釋放 |
| 使用者想回到原本桌布 | 首次套用自動備份;介面與命令列都能一鍵還原 |
| 全螢幕偵測誤判,導致桌布沒更新 | 可在「運作」頁關閉;正對桌面時一律不算忙碌 |
